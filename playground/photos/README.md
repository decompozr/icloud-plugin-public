# Retired Photos experiments

The executable prototypes, standalone package/dependencies and native review/probe
sources were retired on 2026-10-05 after the production implementation moved to
`apps/icloud/src/photos`. They are not a runtime, installation or alternate login
path. Source history remains available in Git before this retirement commit.

Use the [Photos module](../../apps/icloud/src/photos/README.md) and
[active capability plan](../../docs/photos-capability-plan.md) for current behavior.
Historical findings remain in [feasibility](../../docs/photos-feasibility.md),
[cloud research](../../docs/photos-cloud-research.md) and the retained handoff.
References in dated evidence to removed probe files describe historical checks,
not commands to run in the current checkout. Live Photo paired upload remains
unfinished; retiring prototypes does not claim that feature is implemented.
